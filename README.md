# PMS Weekly Report (주간보고 자동화 도구)

## 사용법
1. `PMS_Weekly_Report.exe`를 실행하면 전용 Chrome 창이 자동으로 열리며 **Redmine**과 **PMS** 2개 탭이 실행됩니다.
2. 새로 열린 Chrome 창의 두 사이트에 모두 **로그인**한 뒤, 검은색 프로그램 창에서 **Enter**를 누릅니다.
3. 화면 안내에 따라 **사업관리 항목 포함 여부**와 **90일 이상 장기 일감 포함 여부**를 번호(또는 Enter)로 선택합니다.
4. 생성된 주간보고 미리보기를 확인하고 **`y`를 입력**하면 PMS에 진척률(100%)과 금주 실적/차주 계획이 자동 입력 및 임시 저장(`작성중`)됩니다.
5. 마지막으로 PMS 브라우저 화면에서 내용을 최종 확인한 후 진행상태를 **[제출]**로 변경하여 저장하면 완료됩니다.
